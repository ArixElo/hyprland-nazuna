# Walker Nazuna Theme

Motyw do Walkera inspirowany klimatem Nazuny Nanakusy: ciemny, neonowo-fioletowy, nocny.

## Instalacja

1. Skopiuj katalog `theme-nazuna` do:
   `~/.config/walker/themes/nazuna`
2. Skopiuj `config.toml` do:
   `~/.config/walker/config.toml`
   albo tylko ustaw w swoim configu:
   `theme = "nazuna"`
3. Uruchom ponownie Walkera.

## Zawartość

- `style.css` — pełny styl
- `layout.xml` — główny układ
- `item*.xml` — widoki elementów listy
- `preview.xml` — preview
- `keybind.xml` — kapsułki skrótów
- `config.toml` — przykładowa konfiguracja
